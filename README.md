# CS-405 Secure Coding Portfolio

## Overview

This portfolio presents selected work completed in SNHU’s CS-405 Secure Coding course. It demonstrates my work in secure software development, security policy, risk assessment, and secure coding practices.

---

## Included Artifacts

- Project One Security Policy
- Project Two Security Policy Presentation
- Coding project ZIP files
- Module Eight portfolio journal reflection (Word document)

---

## Project One: Green Pace Security Policy

The Green Pace Security Policy establishes secure coding standards and security practices for software development. It addresses common coding risks, risk assessment, defense in depth, encryption, and the use of automated tools to support secure development.

---

## Project Two: Security Policy Presentation

The Project Two presentation explains how the security policy can be applied. It covers coding standards, threat assessment, automated detection, testing, and security practices for protecting systems and data.

---

## Coding Projects

The coding ZIP files contain project work completed during the course, including:

- Numeric overflows
- SQL injection
- Buffer overflow
- Unit testing
- Static code analysis

---

## Portfolio Journal Reflection

The Module Eight journal reflects on what I learned in the course, including how secure coding practices, risk assessment, and Zero Trust influenced my approach to software security.

---

## Skills Demonstrated

- Applying secure coding practices
- Identifying and assessing software risks
- Using testing and code analysis to find potential weaknesses
- Developing security policies and recommendations
- Communicating security concepts clearly
